**<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">常用 options</font>**

```plain
useFetch('/api/posts', {
  method: 'GET',
  query: { page: 1, limit: 10 }, // URL 参数
  headers: { Authorization: 'Bearer token' },

  pick: ['id', 'title'], // 只取需要字段
  watch: [page], // 依赖变化重发
```
